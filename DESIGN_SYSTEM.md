# Website design

The current portrait-led direction uses deep green, warm cream and sand surfaces, clear section transitions, restrained IBM Plex Serif headings and readable IBM Plex Sans supporting text.

The opening pairs a substantial portrait with a direct description of POSH support. The scope section uses native disclosure controls; the working relationship, personal biography and contact area each have distinct treatments. On narrow screens, the portrait precedes the introductory text.

This direction follows the user's reference gallery at https://www.sitebuilderreport.com/inspiration/lawyer-websites. Reference branding, photographs and marketing copy were not copied. Portraits are retained from the supplied repository.

Keep factual scope boundaries, readable type, visible focus, reduced-motion handling and a single responsive implementation. Do not add client details, testimonials, rankings, fabricated qualifications or unsupported legal mandates.
